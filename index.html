Conectar con Dropbox

Solo necesitas hacerlo una vez. Tus credenciales se guardan en este navegador y el dashboard se actualizará automáticamente.

  1. Ve a dropbox.com/developers/apps
  2. Crea App → Scoped access → Full Dropbox
  3. Pestaña Permissions → activa files.content.read
  4. Pestaña Settings → genera Access Token
  5. Pega el token abajo junto con la ruta de tu archivo
Dropbox web → clic derecho archivo → Compartir → Copiar enlace
